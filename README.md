# 停车入库教练 · Parking Coach

一个纯代码程序化建模的 three.js 停车教学网站：倒车入库（左/右/窄道）、侧方停车（空库/前后有车）、自定义障碍场地。

**在线体验：** https://mr-funny.github.io/parking-coach/

## 特色
- 自行车模型（Ackermann）车辆物理，后轴参考点，自动挡（W/↑ 前进、S/↓ 后退）
- 4 个视角：跟随 / 俯视 / 车内驾驶 / 回头看后窗
- 左右外后视镜 + 内后视镜实时渲染（WebGLRenderTarget，镜像翻转）
- 后视镜点位辅助：镜中标出要找的库线 / 库角与车身参考点，车内标出发动机盖点位
- 分步引导模式 + 练习模式，参考科目二评分，给出"打方向偏早/偏晚多少米"的建议
- 预测轨迹、转弯圆、幽灵车、轨迹回放（含慢动作）
- 摆放雪糕筒 / 障碍车，按关卡保存在浏览器本地
- 单个 `index.html`，无构建、无外部模型/贴图/音频，桌面与手机均可用

## 操作
| 按键 | 功能 |
| --- | --- |
| W / ↑ | 前进（倒车中按 = 刹车） |
| S / ↓ | 后退（前进中按 = 刹车） |
| A D / ← → | 方向盘 |
| C | 一键回正 |
| X | 刹车 |
| 空格 | 手刹 |
| 1–4 | 切换视角 |
| P / V / H | 点位辅助 / 后视镜画中画 / 提示 |

> 点位数值来自驾校经验总结，不同驾校与车型会有差异，不是考试标准。
